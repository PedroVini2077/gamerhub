## O que já se sabe, e não precisa ser redescoberto

- **Proporção manda.** A primeira versão foi desenhada num quadrado e leu como
  **shuriken**, não como raio. A referência é ~**1:1.9** (quase duas vezes mais
  alta que larga), e é isso que faz as duas lâminas dominarem as duas asas.
- **A 16 px o furo hexagonal quase fecha.** O `../README.md` já previa: a versão
  pequena é *"deliberadamente mais simples"*. A saída é furo **maior** no
  tamanho pequeno, não a mesma geometria espremida.
